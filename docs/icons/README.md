# Diagram icon sources

The diagram consumes transparent PNGs because Graphviz handles those reliably,
but vector originals are kept alongside them where available. The PNG variants
are rendered at 1024×1024 so the README diagram remains crisp at high DPI.

- Actual Budget, Alloy, ntfy, Prometheus, Traefik Proxy, and Vikunja use SVGs
  from [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons/tree/main/svg).
- `cloudnativepg.png` is the mammoth mark isolated from CloudNativePG's
  [official organization artwork](https://github.com/cloudnative-pg/.github/tree/main/logo).
- Product names and marks belong to their respective projects.
